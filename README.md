# Protótipo Qualifica Cidadão — catálogo, cursos e carrinho demonstrativo

Este pacote contém um protótipo estático em HTML/CSS/JS para estudo visual e de usabilidade.

## Contexto

- **Plataforma fictícia:** Qualifica Cidadão
- **Órgão de referência:** Prefeitura Municipal de Vila Horizonte — Município fictício
- **Finalidade:** demonstração visual e estudo de arquitetura de portal de cursos
- **Integração real:** não possui

## Arquivos

- `index.html` — página inicial
- `cursos.html` — catálogo de cursos
- `curso.html` — página individual de curso
- `carrinho.html` — carrinho demonstrativo
- `assets/` — estilos, scripts, imagens e logotipos

## Observações

- Os cursos, preços e imagens são ilustrativos.
- Não há matrícula, checkout ou cobrança real.
- O material foi pensado como protótipo independente do ambiente AEM.
